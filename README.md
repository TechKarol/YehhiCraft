# YehhiCraft
Launcher przeglądarkowy (PWA) dla klienta Eaglercraft. Bez backendu, ścieżki względne (działa w podkatalogu GitHub Pages). Interfejs PL/EN.
**Klient gry nie jest dołączony** – patrz `game/README.md`. Bez niego przyciski gry pokażą komunikat o brakujących plikach.
Start lokalny: `python -m http.server 8000` → http://localhost:8000. Docs: `docs/`.
